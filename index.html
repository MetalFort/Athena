        Desligada

        Cole aqui o bloco firebaseConfig do seu projeto Firebase (é gratuito).

        Como criar o Firebase (passo a passo)
        1. Abra console.firebase.google.com e entre com sua conta Google.
        2. Adicionar projeto → nome "atena" → pode desligar o Analytics → Criar.
        3. Menu Authentication → Começar → Google → Ativar → escolha seu e-mail → Salvar.
        4. Menu Firestore Database → Criar banco → local southamerica-east1 (São Paulo) → modo produção.
        5. Na aba Regras do Firestore, cole as regras do arquivo FIREBASE.md e clique em Publicar.
        6. Engrenagem → Configurações do projeto → Seus apps → ícone </> (Web) → apelido "atena" → Registrar.
        7. Copie o bloco firebaseConfig que aparecer e cole no campo acima.
